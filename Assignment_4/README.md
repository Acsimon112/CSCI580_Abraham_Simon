# ASSIGNMENT #4

This assignment uses most of the skeleton provided, with some additions to make the code functional. These replace the TODO sections found in the skeleton code. Additionally, there is some extra data taken for comparison's sake that was not originally included inside the skeleton.

## Simulated Annealing
Running simulated_annealing_tsp() performs the simulated annealing algorithm in the context of a traveling salesperson problem. it returns the best tour discovered, the best length recovered, a list of the best lengths, as well as a history of accepted and rejected deltas for use in data gathering.

## Genetic Algorithm

Running GA performs a genetic algorithm using tournament select and order crossover to decide its populations. It returns data in the form of the best tour, best length, a history of best lengths, and the average fitness of its populations.
